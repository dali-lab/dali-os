Every project has its own Drive on the **Drive** tab of its project page. Documents written in DALI OS and uploaded files live together in one folder tree. For the general Drive, see [Drive](/help/articles/drive). This article covers what is specific to projects.

## Add things to the project

Open [Projects](/projects), pick a project and open the **Drive** tab. Click **New** and choose:

- **New document**: a collaborative document in the project.
- **New folder**: name it, then drag or move items into it.
- **Upload files**: pick one or more files from your computer. They land in the folder you are looking at.

**New** is greyed out if you are not Core or staffed on the project. Only Core and project team members can add, rename, move or delete project files. Any other lab member can open the tab and read the documents and files.

Use the type filter at the top to show only documents, notebooks, whiteboards or files. Click an item's three-dot menu, or right-click it, for **Open**, **Download** (files), **Add to favorites**, **Share…** (documents and folders), **Rename**, **Move to…** and **Delete**. Deleting moves an item to the trash, and a folder has to be empty first.

## Attach a file to a task

Open a task on the project's **Progress** tab and use **Work files**. **Upload files** adds new files to the project and attaches them. **Attach existing** links a file already in the project's Drive. **Unlink** removes the link from the task and leaves the file in the Drive. See [Tasks and the project board](/help/articles/tasks).

## Share with a partner

If the project has an active partner organization, files and documents in its Drive get one more menu item, available to Core and the project team. Choose **Share with partner** on an item and confirm **Share with partner?**. It takes effect immediately. Choose **Stop sharing with partner** to take it back. Without an active partner, the menu item does not appear.

What a partner sees:

- Only items you shared. Nothing is shared by default.
- Folders are not shared on their own. A folder appears for the partner only when something inside it is shared, and it lists only the shared items in it.
- Partners can open shared documents and preview or download shared files. They never see tasks, other files, or who is assigned to what.

To check what a partner sees, open the project's page-bar menu and choose **Partner view**. Any lab member can open this preview. See [Projects](/help/articles/projects).

## Who changed what

Core and the project team see a **Recent activity** list on **Project details**. It shows when someone added a file, changed a file's or document's partner sharing, or changed the public write-up.
