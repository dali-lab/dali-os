The Resource Hub gives each domain one place for its guides, its feedback wall and its collected inspiration. Each hub has three tabs: **Resources**, **Crit Wall** and **References**.

## Find a domain's hub

Open [Resource Hub](/resource-hub) in the sidebar. Each card is one domain's hub. Select a card to open it. Everyone sees published hubs. A card marked **Draft** is still being written, and only the people who can edit it see it.

## Read and edit a hub

The **Resources** tab is a page you read like any document. You can edit it if you are Core, a lead of the hub's domain this term, or the member who created the hub. Everyone else sees it read-only.

- A new hub starts as a draft. Select **Publish** to let all members see it.
- After that the button reads **Update**. Your changes save as you type, and **Update** publishes the current version.
- Select **Preview** to see the page as members see it, and **Back to editing** to return.
- Select **Delete** to remove the whole hub.

## Change the title and cover

If you can edit the hub, the gear at the end of the tab row opens **Edit title and cover**. Change the title, then pick a pattern or upload an image for the cover, and select **Save**.

## Add a hub

There is one hub per domain. Core can add a hub for any domain, and a domain lead can add one for a domain they lead. On the [Resource Hub](/resource-hub) page, select **Add**, name the hub, pick a cover and choose the domain. A domain that already has a hub is not available to pick.

## Share work on the Crit Wall

The **Crit Wall** tab is where members of a domain post work in progress and ask for thoughts.

1. Select **Share work**.
2. Upload an image or a file, or paste a link to something like Figma, Google Docs or a website.
3. Add a title and a question if you want. Without a title, DALI uses the file name or the page name.
4. Under **Post as**, choose your name or **Anonymous**.

Use the filter to show **All work**, **Mine** or **Needs feedback**, which lists posts with no comments yet. You can edit the title and question of your own post.

The wall shows the newest posts first. Select **Load more** at the bottom for older ones.

### Anonymous posts

An anonymous post hides your name from other members, including on your comments on that post. Core and the domain's leads can still see who wrote the comments, so they can moderate.

### Comment on a post

Open a post and write a comment. Type @ and a name to mention someone. On an image post, switch to **Comment** mode, or press C, and click the image to leave a pinned comment at that spot. Switch back to **View** to look at the image without placing pins.

### Delete a post or comment

You can delete your own posts and comments. Core and the domain's leads can delete any post or comment on their Crit Wall. Deleting a post also deletes its comments.

## Add a reference

The **References** tab collects work and inspiration shared by the domain.

1. Select **Add reference**.
2. Upload an image or file, or paste a link.
3. Add a title, or leave it blank to use the link or file name. Add a note about why it is worth sharing if you like.
4. If you made it, check **I made this**. Otherwise, you can name the creator or source.

A reference marked **DALI-made** is credited to the member who shared it. Other references show **Shared by** with your name, plus the creator you entered.

You can edit and delete your own references. Core and the domain's leads can delete any reference.

The newest references show first. Select **Load more** at the bottom for older ones.
