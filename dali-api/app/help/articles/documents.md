Documents are shared pages that several people can edit at once. You see other people's cursors as they type, and changes save on their own. Create one from [Drive](/drive) with **New** then **New document**. See [Using Drive](/help/articles/drive).

If you only have view access, you read the same page but can't edit. Who can open or change a document is covered in [Sharing and visibility](/help/articles/sharing).

## Write with blocks

Click the title to rename the document, or click its name in the breadcrumb at the top. Above the title you can add an icon and a cover image. Core members can also add tags to project and General documents.

Type `/` on an empty line to open the slash menu, then keep typing to filter it. It offers headings, bullet, numbered and check lists, quotes, code, dividers, toggle lists, tables, images, files, videos, callouts, bookmarks, a page break and two or three column layouts. Press Enter to insert the one you highlighted.

To add an image or file without the menu, paste it (⌘V or Ctrl+V) or drag it onto the page from your computer or another site. It uploads where you drop it, or below the line you're on. A table cell can't hold an image, so one pasted or dropped in a table goes below the table.

Drag the handle at the left of a block to move it. Its menu has **Duplicate**, **Colors** and **Delete**.

## Mention people and pages

Type `@` and start a name to mention a member, or a page title to link to it. Mentioning a person notifies them.

## Comments

To comment on a passage, select the text and click **Add comment** in the toolbar that appears. You need comment access or higher. Comments show beside the document, or at the bottom on a narrow screen, and only once the document has some. Use **Hide comments** or **Show comments** in the document's menu (the three dots) to toggle them. You can reply to a comment, react to it with any emoji (including the lab's custom ones), and edit or delete your own from the **More actions** button (the three dots) that shows when you hover it. Core can delete any comment.

## Find and replace

Press the Find shortcut (Cmd-F on Mac) or choose **Find & replace** from the menu.

## Version history

Choose **Version history** from the menu, or press Cmd-Option-Shift-H. The panel lists earlier versions: ones you or others named, and auto-saved ones. Select a version to preview it. If you can edit the document, use the pencil to **Name this version** or rename it, and **Restore this version** to replace the live document with it, after you confirm. People who can only view or comment can preview versions but not name or restore them.

## Ask AI

When the lab's AI is switched on, the slash menu has **Ask AI**, and selecting text shows an **Edit with AI** button. The AI bar offers:

- With text selected: **Improve Writing**, **Fix Spelling & Grammar**, **Translate…** and **Simplify**.
- With nothing selected: **Continue Writing**, **Summarize**, **Add Action Items** and **Write Anything…**.

The result appears in the document first. Click **Accept** to keep it or **Revert** to undo it. Each person has a daily limit on AI requests.

## Add a task

Type `/task` to add a task from inside the document. You need a title and a project. In a project's document the task files on that project. A task without a deadline starts in Backlog, and any other status needs a deadline. The option only appears if you can edit the document and can file tasks on at least one project.

## Menu actions

The three-dot menu on a document also has:

- **Duplicate**, **Reveal in Drive** and **Move to…** (if you manage the document's sharing).
- **Mark as template** and **Unmark as template** (if you can edit).
- **Import Markdown** and **Import template** (if you can edit). **Import Markdown** accepts a .md file or a .zip.
- **Page style** (if you can edit): choose Default, Serif or Mono, and turn on small text or full width.

## Export and print

In the document's three-dot menu, choose **Download PDF**, **Download Word** or **Download Markdown**. Where the page shows a **Download** button instead, it offers PDF, Word and Markdown. **Print / Save as PDF** uses your browser's print dialog. A document with images or other uploads downloads as a .zip with the Markdown file and a folder of its files, so the images show up in other apps. Without uploads it downloads as a single .md file. Exports include only what you can already open.

## Import Markdown

Choose **Import Markdown** in the three-dot menu and pick a .md, .markdown or .txt file, or a .zip like the one **Download Markdown** makes. The content is added to the document. Images are copied into DALI from the .zip, from other sites and from Google Docs downloads. An image inside a sentence or a table moves to its own line after it. If an image can't be copied, it stays as a link and you see how many.
