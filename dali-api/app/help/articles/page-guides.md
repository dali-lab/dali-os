Many pages have a built-in guide that explains what the page is for and how to use it. Look for the **Guide** button (a book icon) in the top bar or page bar.

## Open and close a guide

Click **Guide**. The guide replaces the page you were on. Click the X (**Close guide**) at the top right to go back. The address gets `?doc=1`, so you can share a link that opens the guide directly.

## Read a guide

The title sits at the top with the line "Maintained by" and the person's name, or "No maintainer assigned yet". On the left is the list of **Sections**. Click one to read it. A section can include text, images, files, side-by-side layouts, and a walkthrough video. Sections that are not written yet say "No guide written for this section yet."

Below the guide there is a comment thread. Anyone can leave a comment or question there.

## Edit a guide

Only the guide's maintainer and Core can edit it. They see an **Edit** button next to the close button.

1. Click **Edit**. You can change the **Guide title** and each section.
2. Use **Add** under Sections to add one. Rename it, move it with the up and down arrows, or delete it.
3. Write in the editor. Use **Upload video** (or **Replace video**) to attach a walkthrough video.
4. Click **Save**, or **Cancel** to discard changes.

A guide needs a title, at least one section, and every section needs a title. Deleting a section removes everything in it, and the app asks you to confirm.

Only Core can assign the maintainer. While editing, Core sees a picker to search members by name. A newly assigned maintainer gets a notification.
