Projects are the lab's client work. The [Projects hub](/projects) lists every project, and each project has its own page with its plan, tasks, files and details. For the tasks themselves, see [Tasks and the project board](/help/articles/tasks). For files, see [Project files and sharing](/help/articles/project-files).

## Find a project

Open [Projects](/projects) from the sidebar. Every lab member can see every project.

- Type in the search box to match a project name or a partner name.
- Use the filter bar to narrow by **Status**, **Term**, **Website** or **Partner**. The list opens filtered to the current term, so past projects are hidden until you change or clear the Term filter. Clear the filters to see everything.
- Switch between cards and a list with the view toggle. Click a project to open it.

The **Website** filter is about the public showcase card, with values like Published, Needs review, In progress, Not started, Archived and Not written up.

## Start a project

Only Core can create projects. Click **New project** on the hub, then fill in a name, an optional description, a status, a start term and a partner. If your lab has project templates, pick one under **Start from template** to begin with its epics and structure. Pick **Blank project** to start empty. Click **Create** to open the new page.

## The project page

The top of the page shows the project's icon, name, terms and roles. Below it are tabs:

- **Progress**: the planning timeline of epics, stories and sprints, with the task board underneath. See [Tasks and the project board](/help/articles/tasks).
- **Drive**: the project's documents and files.
- **Project details**: the description, this term's challenge, partner organizations, details like the GitHub team, Slack channel, repositories, Figma and deployment, the team for each term, and the principal investigators.
- **Mentorship**: only visible to lab mentors and Core.

Opening a project from a link to the old Overview or Tasks tabs lands you on **Project details** or **Progress**.

## Who can change what

- **Everyone in the lab** can read any project page.
- **Core, and anyone staffed on the project in any term**, can edit content: rename the project, change its icon, edit the description and details, work with epics, stories and tasks, and manage the project's files. Everyone else sees the same page read-only.
- **Only Core** can change project scope and settings: status, visibility, recording policy, declared roles, terms, challenges, partner links and principal investigators. Core also reassigns a team member's level from the Team section.

Core principal investigators are listed per term under **Principal Investigators** on **Project details**.

## Project settings

Core and staffing leads see a gear next to the tabs. Click **Project settings** to open it. Staffing leads can read it, but only Core can change it, save a template or delete the project. It holds:

- **Status**: Active, Paused or Archived.
- **Visibility**: a private project is left out of project dropdowns on forms. It is still listed on the hub and in search, and its team still sees it.
- **Recording policy**: turn meeting recording off for this project's meetings.
- Declared roles (domains), the project's terms, and a written challenge for each role in each term. The current term's challenge shows on **Project details**.
- **Save as template**: turn the project's structure into a template for new projects.
- **Danger zone**: **Delete project** asks you to type the project name first. It is blocked while the project still has things attached, and the message lists what.

## Partner view and public view

Each project has two previews. The project's page-bar menu lists the other views, so from the project page you can choose **Partner view** or **Public view**, and from either preview you can go back to **Internal view**.

- **Partner view** shows what a partner organization sees on its portal: the description, the current team, the plan timeline with epics and stories, and the files and documents your team shared with the partner. Tasks and cancelled epics are never shown. Any lab member can open the preview.
- **Public view** is the project's card and write-up as [dali.website](https://dali.website) shows it. Edit it in place: the public name, a one-line statement, year, product, sector, tech, partner, links, the write-up sections and a media gallery. Core or anyone staffed on the project can edit the content and click **Save card**.

## Publish a showcase

The status menu at the top of **Public view** has Not started, In progress, Needs review, Published and Archived. Only Core can change it. Choosing Published asks you to confirm, because it makes the project visible to anyone on the internet at dali.website. Anything other than Published keeps the project off the site.
